    body: "I redesigned and rebuilt the site as a fast, static website with Astro, and redirected the old addresses with 301s so the rankings the site already had were not lost. Each main treatment now has its own page written with local search in mind (BIAB nails, lash lift or GEL-X nails in Sydney), with prices, durations and answers to common questions. I built an admin panel so the salon can update prices, opening hours and services on its own, and the service menu mirrors its Fresha booking listing. I also set up Google Analytics 4 and Google Search Console, with booking buttons tagged so the salon can see which pages lead to bookings, and I run the salon's Google Ads and Meta Ads campaigns."
